# ⭐ Featured Projects

## 🧑‍💼 Placement Copilot

**AI-powered placement assistant that turns recruitment emails into structured job workflows.**

The system monitors placement-related emails, classifies them using an LLM, extracts recruitment links, validates URLs and uses browser automation to retrieve job information.

**Architecture:**

`Gmail API → FastAPI → PostgreSQL → LangGraph → Groq LLM → Playwright → Job Parser`

**Highlights:**

* Email ingestion and persistence
* LLM-based email classification
* Conditional LangGraph workflows
* Structured Pydantic outputs
* Authenticated Playwright scraping
* Job information extraction
* Duplicate detection and workflow states

`Python` `FastAPI` `PostgreSQL` `LangGraph` `Groq` `Playwright` `Pydantic`

---
